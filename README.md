# Truffle Hunter

An early stage AI native mobile app that helps college students meet in person, founded and run solo. Currently paused.

I designed and built Truffle Hunter myself: the research, the product decisions, the interaction design, the design system and the working prototype in code.

## What it does

College students feel lonely while surrounded by people. Truffle Hunter shows who nearby is open to meeting right now, then gives both people an icebreaker so the first conversation is easy.

## What I built

* A working mobile prototype in React Native, TypeScript and Expo, built with Claude Code
* A design system in code: shared components plus color, spacing and type tokens
* Registration and onboarding flows, an availability toggle, and a Discover screen with a custom styled map and walking directions

## How I validated it

* 12 validation sessions with 31 participants
* 92% of participants endorsed the icebreaker
* The concept grew out of seven user interviews and three concept tests on an earlier venture, Hi Stranger!

## Run it locally

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and add your own Google Maps API key
3. Start the app: `npx expo start`, then open it in Expo Go
